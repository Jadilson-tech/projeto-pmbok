# Projeto PMBOK

## Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de apresentar os principais conceitos do *PMBOK* (*Project Management Body of Knowledge*), guia de boas práticas utilizado no gerenciamento de projetos.

O site foi criado para fins acadêmicos, utilizando tecnologias básicas do desenvolvimento web.

---

## Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**

---

## Estrutura do Projeto

```plaintext
projeto-pmbok/
│
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── img/
```

---

## Funcionalidades

- Página estruturada em HTML semântico
- Estilização externa com CSS
- Navegação com menu interativo
- Inserção de imagens
- Vídeo incorporado do YouTube
- Responsividade básica
- Separação de arquivos por função

---

## Objetivo

O principal objetivo deste projeto é demonstrar conhecimentos fundamentais em desenvolvimento web, organização de arquivos e publicação de páginas utilizando o GitHub Pages.
